Repository Package

The portfolio package includes a repository-ready folder with source code, headers, a Doxyfile, README, and .gitignore. This is intended to satisfy the submission requirement that the repository include source code in a CubeIDE-compatible structure, a Doxyfile, and a README linking to documentation.

Doxygen Notes

The code is prepared for Doxygen-style documentation. The most important application-level documentation is in app.c, which describes the finite state machine, safety interlocks, and PI controller. Additional module headers expose concise APIs for each subsystem.

# Generate Doxygen locally if installed:
doxygen Doxyfile

# Then open:
docs/html/index.html

Portfolio Source Snapshot

The portfolio source version updates app.c to implement closed-loop PI speed control using the output shaft encoder. The rest of the modules preserve the motor PWM, actuator, button debounce, encoder, and UI separation.
