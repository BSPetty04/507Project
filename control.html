Control System Intent

The intelligence of the project is a safety-supervised PI speed controller. The controller combines user-selected speed commands, encoder-based output shaft feedback, and door/actuator safety interlocks to operate the gearbox in a controlled and repeatable way. The TFT display closes the user-feedback loop by reporting selected target speed and measured input/output shaft speeds.

Closed-Loop PI Speed Control

The output shaft encoder is the feedback sensor for speed regulation. The user selects a target output shaft RPM from preset values. The firmware computes the difference between the target speed and measured output shaft RPM, then updates motor PWM duty cycle through a proportional-integral controller.

error = target_rpm − measured_output_rpm
integral = integral + error · Δt
PWM_duty = Kp · error + Ki · integral

The controller clamps duty cycle between 0 and 999 timer counts and limits the integral term to prevent windup when the motor saturates or when the system is stopped.

Kp2.0Immediate correction based on current speed error.

Encoder RPM and Gear Ratio Modeling

Encoder RPM is calculated by sampling timer counts periodically and converting the count difference into revolutions per minute.

RPM = (encoder_count_delta / counts_per_revolution) / sample_time_minutes

The project can also estimate the observed gear ratio by comparing input and output shaft speeds.

observed_gear_ratio = input_shaft_RPM / output_shaft_RPM

Safety Mechanisms

Safety FeatureImplementationReason
Door switch interlockMotor can only start if SW_NO reports the enclosure is closed.Prevents gear train operation while the door is open.
Door-open stopIf the door opens while running, the controller immediately stops PWM.Prevents unsafe access to moving parts.
Actuator interlockLock/unlock commands are blocked while the motor is running.Prevents mechanical locking movement during rotation.
Fault stateActuator fault input disables motor and actuator outputs.Stops operation when driver fault is detected.

User Interactions

  • Button 1: start/stop the selected speed.
  • Button 2: lock/unlock actuator when stopped.
  • Button 3: cycle through target RPM presets.
  • TFT display: target RPM, input RPM, output RPM, running/stopped state, lock state, door state, and fault state.

Future Improvements

  • Experimentally tune PI gains for smoother transient response and lower steady-state error.
  • Add optional PID derivative damping if the gearbox oscillates near setpoint.
  • Add automatic gear ratio estimation and display it during operation.
  • Add a TFT setup screen for encoder CPR and PI gain adjustment.
  • Add actuator position feedback or limit switches for confirmed lock/unlock state.
  • Add motor current sensing to detect stalls or excessive load.
  • Add USB serial debug commands for tuning, telemetry, and diagnostics.
  • Add event logging for door-open events, actuator faults, and speed-control faults.
